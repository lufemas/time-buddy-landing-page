# Time Buddy Landing Page

This is a static site. Serve the repository root with any static web server, for example `python3 -m http.server`, and open the resulting local URL.

The updates section embeds the EmailOctopus form and requires JavaScript and access to eocampaign1.com.

When assets and store pages are available:

- Replace the three `.screenshot-placeholder` elements in `index.html` with images, including descriptive alt text.
- Replace the itch.io and Steam `.store-card` placeholders with links to the game's store pages.
